Beyond NSE: telling signal from noise in a neuron group

ngm2 uses the normalised Shannon entropy (NSE) of a vector, passed through a sigmoid window, to decide whether a vector carries signal or noise and to scale learning and inhibition accordingly. This page measures how NSE and eleven scale-free alternatives (plus two absolute level measures) behave on real ngm2 responses, recorded at twelve checkpoints over 500k training steps on six datasets (mnist and kmnist continued to 5M), and on two kinds of noise input.

How the numbers were made

  • Model: ngm2, one group of 50 neurons with 5 proximal dendrites each, configs configs/<dataset>.json unchanged. Training was chained from checkpoints at steps 1, 500, 2k, 5k, 10k, 20k, 50k, 100k, 200k, 300k, 400k and 500k (--load-state → -n Δ → --save-state); mnist and kmnist continue through 600k, 700k, 800k, 1M, 1.25M, 1.5M and then every 500k to 5M. Chained save/resume is exact: 200k → 300k → 400k → 500k reproduces a single 300k-step run bit for bit (mnist and dsprites, 0 of 4,072 state datasets differ).
  • Probe: each checkpoint was loaded into a frozen copy of the config (no winner draw, adaptation or branching; verified by diffing state files: only RNG states, the data cursor and io buffers changed) whose inhibitor is random_index with ri_strength = 0. That makes it clamp(raw, 0, 1), an exact identity because the neuron already clamps its activity to [0, 1]. Each probe ran 2,000 steps with --log-buffers, a fresh input seed and the model's own inference noise.
  • Post-inhibition vectors are soft-WTA (S = 5) applied in Python to the pre-inhibition vectors. The mirror matches a frozen run with the real inhibitor to 1.2·10⁻⁷ (one float32 ulp); 75% of entries are bit-exact.
  • Noise inputs: perm = held-out images with pixel positions shuffled independently per image (same intensity histogram, so the same input NSE); unif = iid uniform pixels (dsprites: Bernoulli at the real pixel density). All conditions get the loader's additive input noise U(0, 0.05).
  • Held-out inputs: cifar10 uses its test batch. mnist, emnist, kmnist, dsprites and chairs3d ship training files only here, so their probes draw from the training images in a different order.
