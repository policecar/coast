Max-softmax local inhibition

A softmax over the group output, rescaled so the strongest neuron keeps its activity. The softmax normaliser cancels in that rescaling, so each neuron ends at the leader's activity times exp(−β · gap), where the gap is how far it trails the leader. No entropy, no window: β is the strength, in units of 1/activity.

out_i = max(v) · softmax(β·v)_i / max_j softmax(β·v)_j = max(v) · exp(−β · (max(v) − v_i))

A neuron is raised when exp(−β·gap) > v_i / max, so the kind is not damping-only: with a weak leader the gaps are small, and the rest of the group is pulled up toward it (never above it). Below, ngm2 groups trained with this inhibitor (β = 10 and β = 20) are compared with groups trained with the current default soft-WTA, on mnist, on chairs3d, whose inputs are bright enough to saturate the group, and on chairs3d with inverted pixels (black background).

How the numbers were made

  • Model: ngm2, one group of 50 neurons, configs configs/mnist.json and configs/chairs3d.json unchanged except for the group's inhibitor; "chairs3d inverted" additionally sets the new loader flag "invert": true (pixel → 1 − pixel at load, before the U(0, 0.05) input noise) for training and probes. soft-WTA runs use the default (strength 5, entropy gate as fixed in PR #135); the max-softmax runs reference an inhibitions entry {"type": "max_softmax", "strength": β}.
  • Training was chained through checkpoints at steps 1, 500, 2k, 5k, 10k, 20k, 50k, 100k, 200k, 300k, 400k and 500k with --load-state / --save-state.
  • Probes: each checkpoint ran 2,000 frozen steps (no learning, no branching) with a pass-through inhibitor, on real images and on two noise sets: the same images with pixels shuffled, and iid uniform pixels. That records the group's response before inhibition. The output after inhibition is the run's own inhibitor applied to it, using float32 Python mirrors of the C++ code.
  • The probe continues the training input stream, so at 500k every run sees the same images (checked: inputs differ only by the loader's independent U(0, 0.05) noise). mnist labels come from matching each probe image to its nearest training image; every match was unambiguous.
  • Measures: peak = largest entry; mean = mean entry; active neurons n_eff = sum / max (50 for a flat vector, 1 for a single winner); raised = share of neurons the inhibitor lifted above their pre-inhibition value. Curves show medians over the 2,000 probe vectors.
